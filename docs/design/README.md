# Design

How parts of gh-desk's code are shaped: their members, what each holds, how they relate, with diagrams. These are for whoever changes the code, and are not pages of the site.

A document here describes the code as it is and changes with it, in the same change. The decisions it follows, and their reasons, are in the ADRs it links to ([ADR-124](../adr/124-how-the-code-is-shaped-is-in-docs-design.md)). The package layers are in [architecture.md](../architecture.md).
