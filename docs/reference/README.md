# Reference

Every command, setting and key of gh-desk, in full. These pages are written from the code by tests, so they say what the version on main does; a change to a setting, a key or a command's help changes its page in the same commit.

- [Commands](commands.md): `gh desk` and `gh desk config`, with their flags, as `-h` prints them
- [Configuration](configuration.md): every setting of `~/.config/gh-desk/config.toml`, with what it takes and its default
- [Keys](keys.md): every action and its default keys, by the screen they work on, and how to bind them in the config file

To learn how the parts fit together first, start with the [concepts](../concepts/README.md).
