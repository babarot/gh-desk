# Guides

How to use gh-desk, a step of the day at a time. Each guide shows the keys and settings for one part, with the screen in the playground where it helps; the [reference](../reference/README.md) has every key and setting in full.

- [Tabs and groups](tabs.md): what each tab lists, how a search tab is split into groups, the inbox, and rules that leave pull requests out
- [Reading a pull request](reading.md): the pane under the list, its overview and its diff
- [Selecting by rules](selecting.md): the selection, and rules that pick what can go together
- [Approving and merging](approve-and-merge.md): the confirm popup, and what a merge does and waits for
- [Closing](closing.md): closing with a comment, and the head branches it deletes or keeps
- [Claude](ask-claude.md): asking about one pull request, asking about the tab, and what Claude may do
- [Configuration](configuration.md): the config file, and the changes most people make first

New to gh-desk? Start with [Getting started](../getting-started.md).
