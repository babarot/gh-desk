The pull requests that reach you, at one desk.

gh-desk is a gh extension. The pull requests waiting for your review, your own, and your notifications sit in one terminal screen. Read the diff, approve and merge a dozen at once, and ask Claude about the one you are unsure of.

Below is gh-desk itself, compiled to WebAssembly and running in your browser against a made-up GitHub. Nothing you do here leaves the page.

~ — gh desk

Things to try

Look before you merge

p opens the pane under the list: the description beside the checks and reviews. v switches it to the diff, ] and [ move between files, and J K scroll it.

Merge the bots in one go

Move to the bots and press b to unfold them, S to pick the rule dependency bots, then M. The popup says how each will be merged, and Claude reads the release notes for the ones that need care.

Ask Claude about one

i on a pull request asks Claude to review it, in a worktree of its head. ctrl+r then drafts the review to post. Here the answers are written in advance.

Or tell Claude what you want

C and type merge the bots with passing checks. Claude plans what to show and select; enter applies it, and nothing is sent until you confirm.

Your notifications

4 or tab goes to the inbox: the pull requests in your notifications, with why each is there. d marks one done.

Every key

? lists the keys of the screen you are on. They are bound by action name, and each can be changed in the config file.

Install

gh-desk runs on the GitHub CLI and its login. Claude is optional: install Claude Code for i and C.

gh extension install babarot/gh-desk

Then run gh desk. The first run writes ~/.config/gh-desk/config.toml, with every setting described and commented out.
