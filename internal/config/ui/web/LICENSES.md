# Third-party code in this directory

- `htm.js`: htm 3.1.1 (Apache-2.0, https://github.com/developit/htm), which bundles Preact (MIT, https://github.com/preactjs/preact).
- `icons.json`: icons of Lucide 0.460.0 (ISC, https://github.com/lucide-icons/lucide).
- `xterm.js` and `xterm.css`: xterm.js 5.5.0 (MIT, https://github.com/xtermjs/xterm.js) and its addon-unicode11 0.8.0 (MIT), as published on npm under `@xterm/xterm` and `@xterm/addon-unicode11`, with the source map comments removed.
